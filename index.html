Implied P(deal) = (price − break) / (offer + net dvd − break), risk-neutral, capped 0–100 %. Expected return is ≈ 0 with implied probabilities by construction; it only says something once you override P(no-deal). Deals trading through terms show P(deal) = 100 %.

Amber cells are inputs. Size is in whatever unit you like (set 0 to exclude). Break price blank = target price × (1 − default downside). P(no-deal) blank = implied. Gross spread = (offer + net dvd − price) / price, JPM's dvd-adjusted convention; annualised = spread × day count / days to expected close. Inputs persist in this browser.
